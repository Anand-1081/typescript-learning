## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Anand-1081/typescript-learning.git
```

### 2. Navigate to the project

```bash
cd typescript-learning
```

### 3. Install TypeScript

If TypeScript is not already installed:

```bash
npm install -g typescript
```

Check the installation:

```bash
tsc --version
```

### 4. Compile TypeScript

```bash
tsc
```

This converts the `.ts` files into JavaScript files according to the settings in `tsconfig.json`.

### 5. Run the JavaScript

```bash
node app.js
```
